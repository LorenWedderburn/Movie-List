# Movie-List

# --Overview--

A movie discovery app built with Vue.js and the TMDB API. Search for any film and build your own personal favourites list.

🎬 **Live Demo:** [renware-movielist.netlify.app](https://renware-movielist.netlify.app/)

## --Features--

- Search for movies in real time using the TMDB API
- View movie details including title, poster, and overview
- Add and remove movies from a personal favourites list
- Clean, responsive UI

## --Tech Stack--

Frontend: Vue.js, JavaScript, CSS  
Build Tool: Vite  
API: TMDB (The Movie Database)  
Deployment: Netlify
